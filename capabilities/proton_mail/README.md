# Proton Mail (Microsoft Edge)

- **Router:** **`browser`**, **`start_url`** (required). Optional **`navigation`**: **`edge_then_cdp`** (default — recommended) | **`playwright_persistent`** (legacy; some sites drop cookies under automation-only launches). **`cdp_port`**, **`cdp_connect_wait`**, **`edge_executable`** (when `msedge` is not on `PATH`).
- **`edge_then_cdp`:** tries **`connect_cdp`** first; on Windows waits for Edge to **fully quit** (profile lock). With **`prelaunch_open_app`** (default in ROUTER), runs **`open_app`** (Edge) then the mailbox URL, then prompts you to **close all Edge windows** again before spawning **one** Edge with **`--remote-debugging-port`**. The inbox is opened afterward via **`microsoft-edge:`** / OS handlers (URL is **not** appended on the spawn argv — helps Proton treat the session less like a raw automation launch). Set **`prelaunch_open_app`: false** to skip the ritual when you closed Edge yourself first.
- **`playwright_persistent`:** only if you deliberately want `launch_persistent_context` (often treated as automation and may prompt login).
- **Entry:** `run.py` — Mark spawns it via **`run_capability`** (stdin = one JSON object). Prints one JSON line to stdout; exit code 0 on success.
- **Stdin fields:** `action` — `open` | `inbox` (default) | `compose` | **`send`**; `url` — optional override for this run; `dry_run` — if true, only reports what would run (no browser).
- **`send`:** requires **`to`** and **`body`**; optional **`subject`**. Opens compose (same as `compose`), fills fields with **`browser_control` `smart_type` / `smart_click`**, then **Send** (best-effort; external-address confirmations may block automation).
- **`read_screen`** (no CDP / no Playwright): **`open_app`** + inbox URL (`ROUTER` / `microsoft-edge:` handoff), wait **`read_screen_settle_sec`**, then one **`analyze_screen_sync`** screenshot → **local Ollama vision** (`ollama_vision_model`) or **Gemini** (`gemini_api_key`). Stdin: optional **`question`** or **`text`**, **`skip_open`** (already on inbox), **`settle_sec`**. JSON stdout: **`answer`**, **`ok`**. Sign in yourself in Edge; Mark does **not** store Proton credentials. Vision only sees pixels on your monitor — no API password handshake.
- **Credentials:** There is nothing for PowerShell to “inject” into Proton’s web session for Mark’s vision path—you stay logged in in normal Edge. Optional: **`SecretManagement`** / **Credential Manager** for *other* scripts you write yourself (`Install-Module Microsoft.PowerShell.SecretManagement`); this repo does not read those stores for Proton today.
- **`send_message`:** platform **`Proton Mail`** uses this playbook for **send** (CDP). For **reading** without automation mail, use **`run_capability`** `action: read_screen`. For the **desktop app**, use platform **`Proton Mail Desktop`**.
- **Session:** After navigation / compose steps, **`run.py` calls `browser_control` `action: close`** for this process’s Playwright session so Edge is not left held for the next playbook. (`dry_run` skips the browser entirely.)
